LLM Speedrun Summary

What was changed

The final submission keeps the starter byte-level GPT architecture and improves the training recipe rather than increasing model size. The main changes were a stronger optimizer, a warmup-and-decay schedule, and gradient clipping.

Best verified result: dev bpb = 2.2130 on the provided evaluation set with the final checkpoint.

Why this is likely the best choice

The baseline score was 2.3718. The tuned optimizer/scheduler run improved it to 2.2130, which is a clear win within the same 2,000-step budget. The model remains small and CPU-friendly, which matters under the hard parameter and runtime constraints.

Human vs machine contribution

Machine-generated work: the baseline experiments, repeated training/evaluation runs, and loss curve measurement. Human-made work: selecting the one hypothesis that matched the evidence, documenting the run log, and keeping the final setup minimal and robust.
